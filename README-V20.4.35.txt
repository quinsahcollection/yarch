Yarch V20.4.35 — Lewati Intro & File Manager

Lewati Intro:
- Buka folder episode pada File Manager.
- Isi Mulai dan Selesai pada bagian Lewati Intro.
- Gunakan format MM:SS atau HH:MM:SS, misalnya 00:00 sampai 01:30.
- Tekan Simpan & Publikasikan.
- Tombol Lewati Intro otomatis muncul di player selama rentang tersebut.

File Manager:
- Pesan error kini menunjukkan apakah perangkat offline atau pembacaan folder gagal.
- Tombol Coba Lagi tersedia tanpa menutup modal.
- Error folder tidak lagi salah dilabeli sebagai Storage terputus.
- Media yang sudah tersimpan tidak dihapus ketika daftar folder gagal dimuat.
