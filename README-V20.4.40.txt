Yarch V20.4.40 — Intro Stabil dan Kontrol Layar Penuh

- Kolom Lewati Intro terdeteksi dari format judul maupun file video; penyimpanan juga memakai deteksi yang sama. Ini menjaga pengaturan tidak hilang pada metadata format lama.
- Tombol Lewati Intro tampil hanya di antara waktu Mulai dan Selesai. Jika video sudah melewati waktu Selesai, tombol memang tersembunyi; kembali ke rentang tersebut untuk memunculkannya lagi.
- Pada layar penuh, garis waktu berada di bagian paling bawah. Tombol kontrol memudar setelah 2,8 detik tanpa sentuhan saat video berjalan, lalu muncul lagi ketika layar disentuh.
- Perbaikan UI intro, garis waktu, volume, serta File Manager dari V20.4.39 tetap disertakan.

Unggah/ganti admin.html, index.html, dan sw-v20.1.js dari paket ini. Setelah selesai, muat ulang aplikasi agar cache baru aktif. Data Firestore dan file media tidak diubah.
