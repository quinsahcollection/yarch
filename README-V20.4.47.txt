Yarch V20.4.47 — Perapian Daftar Terkait Feed

- Ukuran teks keterangan Feed dan judul/meta daftar chapter/episode dinaikkan satu tingkat, termasuk layar ponsel.
- Metadata chapter/episode menampilkan ikon tanggal, durasi video, jumlah tayangan, dan label Sub/Dub dari languageLabels/languageLabel bila tersedia.
- Informasi dipisahkan dengan karakter |. Jumlah halaman tetap ditampilkan untuk chapter komik.
- Thumbnail mengutamakan thumbnail episode atau halaman pertama chapter sebelum cover judul.
- Mempertahankan fitur V20.4.46: tombol konten terkait membuka daftar, jumlah total chapter/episode, dan pilihan item menuju chapter/episode yang dipilih.

Deploy seluruh isi folder yarch-main ke sumber GitHub Pages. Pastikan index.html dan sw-v20.1.js berasal dari paket ini. Tidak ada perubahan struktur Firestore atau file media.
